# Oromia Tourism

Oromia Tourism is a responsive React web application for discovering destinations and learning about the living culture, food, history and landscapes of Oromia.

## Main features

- Interactive Oromia destination map
- Destination markers with place stories
- Video guides where a verified video source is available
- External video search for destinations without an embedded source
- Destination information covering culture, food, clothing, history and experiences
- Gadaa, Siinqee, Safuu, Waaqeffannaa, Qalluu, oral knowledge, Busa Gonofa and Odaa content sections
- Irreecha and Gadaa-related cultural events
- Oromo food and hospitality stories
- Favorites saved in the browser
- Trip planning and itinerary
- Responsive mobile and desktop layouts

## Run locally

```bash
npm install
npm run dev
```

## Content note

Oromo traditions vary between communities and regions. The culture section is a curated starting point rather than a claim to document every Oromo tradition. Cultural descriptions should be reviewed with community and institutional sources before public publication.

## Main sources used for the cultural content

- UNESCO Intangible Cultural Heritage: Gadaa System
- UNESCO documentation on Gadaa, Irreecha and related practices
- Visit Oromia / Google Arts & Culture collections on Oromo culture, food and clothing
- Visit Ethiopia information on Irreecha

The project uses public web sources for reference and does not claim ownership of third-party photographs or videos.


## Cultural image accuracy

Culture-specific imagery in the Culture & Stories page has been mapped to documented Oromo cultural material rather than generic stock photography. The current references prioritize Visit Oromia material hosted by Google Arts & Culture and UNESCO documentation. Each culture card includes a source link so the visual context can be checked.
